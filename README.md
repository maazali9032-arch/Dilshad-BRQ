==================================================

Luxury modest-fashion brand + editorial fashion magazine + premium Hyderabad boutique.

- Elegant

- Sophisticated

- Cinematic

- Feminine but not overly decorative

- Premium

- Modern

- Editorial

- High-end

- Visually impressive

- Extremely polished

Avoid:

- Generic SaaS layouts

- Generic Bootstrap-style cards

- Cheap-looking gradients

- Excessive rounded cards

- Cartoonish icons

- Overly colorful UI

- Template-like sections

- Excessive text

- E-commerce UI

- Basic "Hero + 3 cards + footer" design

Use a sophisticated palette inspired by the supplied showroom photographs:

warm ivory / champagne / soft beige / deep charcoal / black with restrained burgundy or rose accents.

Typography should combine:

- Elegant high-fashion serif typography for major headings

- Clean modern sans-serif for supporting text

Use generous whitespace, strong typography, refined spacing and editorial composition.

ANIMATION / INTERACTION

==================================================

This is extremely important.

The website must feel PREMIUM when scrolling.

Use:

- Smooth scrolling

- Scroll-triggered text reveals

- Image reveal masks

- Subtle parallax

- Elegant page transitions

- Staggered typography animation

- Hover image zoom

- Magnetic/subtle CTA interactions where appropriate

- Sticky navigation transformation

- Smooth gallery transitions

- Elegant mobile animations

Animations should be refined and cinematic, NOT flashy.

Use GSAP / Framer Motion / modern CSS animations where appropriate.

Performance is important:

- Lazy-load below-the-fold images

- Optimize images

- Avoid unnecessary heavy effects

- Maintain excellent mobile performance
